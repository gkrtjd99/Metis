# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.x | Yes |

## Reporting a vulnerability

Do not report security vulnerabilities through public issues or pull requests.

Use [GitHub private vulnerability reporting](https://github.com/gkrtjd99/Metis/security/advisories/new) and include the affected version, impact, reproduction steps, a minimal proof of concept, and any suggested mitigation.
