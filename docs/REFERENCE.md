## Runtime layout

```text
.metis/
├── layout.json
├── config.json
├── state/  persistent: SQLite state and transaction files
│   └── state.db
├── objects/  persistent: Referenced content-addressed evidence
├── generated/  regenerable: Repository, document, symbol, and knowledge indexes
├── cache/  cache: Regenerable query and tokenizer caches
├── logs/  cache: Local execution logs
├── tmp/  ephemeral: Atomic-write and integration staging files
├── worktrees/  ephemeral: Task-isolated Git worktrees
├── benchmarks/  user-output: Benchmark specifications and run reports
└── backups/  recovery: Install-time backups for overwritten host files
```
