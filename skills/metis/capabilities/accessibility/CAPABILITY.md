# Accessibility capability

1. Check semantic elements, names, roles, and states.
2. Check keyboard access and visible focus order.
3. Check focus movement after errors, dialogs, and navigation.
4. Check contrast, zoom, reflow, motion, and reduced-motion behavior.
5. Use browser evidence for user-facing requirements.
6. Record the affected requirement, component, state, and repair guidance.
