# Database capability

1. Check schema constraints and transaction boundaries.
2. Check concurrent read and write behavior.
3. Check query plans when performance can change.
4. Check null, duplicate, retry, and partial-failure behavior.
5. Verify that tests use the real database behavior where practical.
6. Record exact data-integrity risks and repair steps.
