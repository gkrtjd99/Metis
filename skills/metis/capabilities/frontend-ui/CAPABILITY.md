# Frontend UI capability

Load this capability only for a task that includes it.

1. Read the `experience-contract`, `visual-contract`, and `browser-acceptance` artifacts.
2. Reuse the repository's components, tokens, layout rules, and interaction patterns.
3. Implement all required loading, empty, error, success, disabled, and permission states.
4. Keep responsive behavior explicit for each required viewport.
5. Do not create a new design system when a current system exists.
6. Link the result to browser scenarios and current source evidence.
