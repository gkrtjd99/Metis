# Migration capability

1. Define the source state and target state.
2. Check forward execution, interruption, retry, and rollback.
3. Check data validation before destructive steps.
4. Check rollout order and mixed-version behavior when relevant.
5. Require an explicit authority boundary for external or irreversible changes.
6. Record recovery evidence and residual risk.
