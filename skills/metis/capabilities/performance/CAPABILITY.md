# Performance capability

1. Identify the changed resource and expected load.
2. Measure before and after when a performance claim is material.
3. Check bounded concurrency, queue growth, cache invalidation, and memory retention.
4. Check failure and retry amplification.
5. Use repeatable command or trace evidence.
6. Reject unsupported performance claims.
