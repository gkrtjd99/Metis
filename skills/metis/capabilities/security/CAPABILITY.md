# Security capability

1. Identify every changed trust boundary.
2. Check authentication and authorization separately.
3. Check session lifetime, token handling, secret exposure, and failure behavior.
4. Check path, command, deserialization, injection, and privilege boundaries.
5. Use current source and command evidence.
6. Record a blocking finding when a security claim lacks proof.
