# Visual review capability

Review the integrated interface against current browser evidence.

1. Compare screenshots with the visual contract.
2. Check hierarchy, spacing, typography, alignment, overflow, and responsive behavior.
3. Check every required interaction state.
4. Check that existing design-system components and tokens are used correctly.
5. Record each finding with a path, requirement, screenshot reference, severity, and repair guidance.
6. Do not approve from source inspection alone.
